# sarkari-ki-taiyari-bot

Automation for the [sarkari.ki.taiyari](https://www.instagram.com/sarkari.ki.taiyari/) Instagram page: daily exam-prep Reels, posts and Stories in Hinglish, approved on Telegram.

All keys are stored as GitHub Actions secrets. Never commit a key or credential file to this repository.

## Workflows

| Workflow | When | What it does |
| --- | --- | --- |
| Test setup | By hand | Checks every service and sends a report to Telegram. Posts nothing. |

More workflows (daily content, Telegram check, publisher, engagement, insights, weekly review) are added in the next setup days.
